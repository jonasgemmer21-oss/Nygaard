# 🎮 POLTERABEND ARCADE — HAMBORG EDITION

Et interaktivt polterabend-spil til brug på mobilen under aftenen i Hamborg.

## 🚀 Kom i gang (GitHub Pages)

### Trin 1 — Opret et nyt GitHub-repository
1. Gå til [github.com/new](https://github.com/new)
2. Giv det et navn, f.eks. `polterabend`
3. Sæt det til **Public**
4. Klik **Create repository**

### Trin 2 — Upload filerne
1. Klik **Add file → Upload files**
2. Træk `index.html` og `README.md` ind
3. Klik **Commit changes**

### Trin 3 — Aktiver GitHub Pages
1. Gå til **Settings** → **Pages** (i venstre menu)
2. Under **Source**: vælg **Deploy from a branch**
3. Branch: **main** / **root**
4. Klik **Save**

### Trin 4 — Del linket
Efter ~1 minut er spillet live på:
```
https://[dit-brugernavn].github.io/[repo-navn]/
```
Del dette link i gruppe-chatten — alle åbner det i Safari på iPhone og spillet virker direkte.

## 🎯 Features
- 38 udfordringer fordelt på 4 sværhedsgrader
- 20 præmier fra 2 til 18 point
- Lykkehjulet med drinks (Jäger, Tequila, Vodka, Astra, Alsterwasser m.fl.)
- Dobbelt-eller-ingenting efter hver udfordring
- Kombo-bonus ved 3 udfordringer i træk
- Gommens billede på mønten på startsiden
- Virker 100% offline og på iPhone (ingen internet kræves efter indlæsning)
- Point gemmes automatisk — genåbn siden og fortsæt

## 📱 Brug på iPhone
Åbn linket i **Safari**. Tryk på deleknappen og vælg **"Føj til hjemmeskærm"** for en app-lignende oplevelse.
